# GitHub
*For all collaborators*
**Git** is a version control software that allows you to sync your files across systems. **GitHub** is the most popular (and user-friendly) provider of the open source Git software, so I'll recommend you [create an account on GitHub](https://github.com). Then you can follow my account [ksadwin](https://github.com/ksadwin) so that I can add you to [shrimp-devvin-now](https://github.com/ksadwin/shrimp-devvin-now). Those are the quick points that will get a seasoned developer started, but for beginners, you can see [[About Git]] for the big picture of what Git is and how it works.
## GitHub Desktop
*For contributors to files other than text documents (Obsidian)*
The most beginner-friendly way to interact with repos is by using the [GitHub Desktop app](https://desktop.github.com/download/). This gives you a visual interface through which you can switch to the branch you want to work on (including a new branch), see what files have changed from the version recorded in the cloud, and sync files to and from the cloud. Once you've created an account on the website and I've added you to the repository, you can log into the desktop app and make a local copy of the repo.
# Obsidian
*For all collaborators*
[Obsidian](https://obsidian.md/download) is a [markdown](https://www.markdownguide.org/cheat-sheet/) editing software that turns brain dumps into mind maps by allowing easy organization of disparate text files through folders, links and backlinks, and a clean visualization of the connections between the documents as a live-updating concept map. Because GitHub also publishes with markdown (.md) files, the two work well together for documentation and notes.

Obsidian works within **vaults**, which (much like with Git repos) is just a fancy word for a tracked folder. We'll be sharing a vault within our repo in the folder **Obsidian**, using a Git integration.
## Obsidian Community Plugin for Git
Once you've installed Obsidian and played around with the default vault it created for you, you can [follow the installation instructions](https://publish.obsidian.md/git-doc/Installation) for the 3rd party Git plugin. Note that it may require you to install a standalone, base version of Git separate from GitHub Desktop.

You may need to restart Obsidian for the changes to take place. If you haven't already cloned the repo to your local system, you should be able to use the new plugin to do so; it will be the new *Open Git source control* icon just under the top-leftmost Collapse icon.

# Python 3.x
*Necessary for coders; recommended for writers/editors, artists, & helpers*
You can download Python [here](https://www.python.org/downloads/). Don't scroll down too far where it starts talking about the different numbered versions of everything, just pick the top where it says **Download the latest version** (or a couple lines below it if it doesn't serve you the right OS download button.) Install may take a while and has a lot of options, but generally all of the recommended/preselected options are good, so you can just blindly click yes to everything. In particular, I don't find it's a good idea to install Python anywhere but the location it autosuggests.
## Ren'Py
Once you have Python installed, your next step is [the Ren'Py SDK](https://www.renpy.org/latest.html) (Software Development Kit). On Windows systems, the **.exe** file is your best bet, but if that fails, try the .zip link underneath the buttons. Mac users should download the **.dmg**.
